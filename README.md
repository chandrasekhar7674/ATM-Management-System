# ATM Management System 💳

## 📌 What the project does

This is a simple Python-based ATM Management System.

The user can log in using a PIN and perform basic ATM operations.

## 🛠️ Technologies Used

- Python

## ⚙️ Features

- PIN authentication
- Check balance
- Deposit money
- Withdraw money
- Transaction history
- Change PIN
- Exit

## ▶️ How it works

1. The user enters their PIN.
2. After successful login, the ATM menu is displayed.
3. The user selects an operation.
4. The program performs the selected operation.
5. The user can continue using the ATM until choosing Exit.
